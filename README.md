# 🍅 TomaDis — Deteksi Dini Penyakit Tanaman Tomat

Project machine learning untuk mendeteksi penyakit pada daun tanaman tomat menggunakan model klasifikasi citra berbasis MobileNetV2, yang diimplementasikan ke dalam aplikasi Android.

> **Catatan:** Ini merupakan project kelompok mata kuliah Data Sains 1. Repository ini berisi kontribusi pada bagian machine learning (training model, evaluasi, dan dataset) serta hasil akhir aplikasi dalam bentuk APK. Source code aplikasi Android dikelola oleh anggota tim lain.

## ✨ Yang Ada di Repository Ini
- **Model ML** (`model_plantvillage.keras`) — model hasil training untuk klasifikasi penyakit daun tomat
- **Notebook training** — proses pengolahan dataset hingga training model
- **Evaluasi model** — confusion matrix, training history, dan contoh hasil prediksi
- **APK aplikasi** — tersedia di bagian [Releases](../../releases) untuk instalasi langsung

## 🛠️ Tech Stack
- **Model:** TensorFlow/Keras, MobileNetV2 (transfer learning)
- **Dataset:** PlantVillage
- **Platform Aplikasi:** Android
